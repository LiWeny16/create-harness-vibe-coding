# task-unify-command-surface - PLAN

Compact task record. Keep only facts needed to resume, review, and verify.

## Goal

- Outcome: Unify Harness command/skill discoverability across Claude Code, Codex, and OpenCode; make `wf-browser` built-in; remove the optional `browser-e2e` skill/workflow path.
- Non-goals: Change WF orchestration semantics, add new browser runtime dependencies, or publish a release.

## Decisions

- WF tier: WF-Standard because this is a multi-file scaffold/template/test change with command-surface behavior risk.
- `wf-browser` becomes a common built-in skill and OpenCode command wrapper.
- `browser-e2e` is removed as an installable optional workflow and user-facing skill.
- Browser E2E guidance lives in `.claude/skills/wf-browser/SKILL.md`, mirrored byte-identically to `.agents/skills/wf-browser/SKILL.md`.
- Direct commands keep platform-specific wrappers where required, but shared behavior is documented once and checked by validator/tests.
- Codex custom WF status support was removed after official docs showed only built-in footer items, not a command-backed custom status bar/statusline. Harness keeps Codex startup update checks only.

## Acceptance

- AC-001: Every user-facing `wf-*` command has complete platform coverage: Claude command or direct command, Claude skill where applicable, Codex skill, and OpenCode command wrapper.
- AC-002: `wf-help` is available in Codex as `$wf-help` while preserving direct `/wf-help` semantics for Claude Code and OpenCode.
- AC-003: `wf-browser` is built in by default; default generated projects include `.claude/skills/wf-browser/SKILL.md`, `.agents/skills/wf-browser/SKILL.md`, and `.opencode/commands/wf-browser.md`.
- AC-004: `browser-e2e` is not an optional catalog entry, not generated as `.claude/.agents` skill, and not referenced as an installed workflow command.
- AC-005: Browser guidance uses current Browser Use script-style CLI plus PowerShell examples, stable UI selectors, Playwright/CDP evidence, and component authoring rules for controllable UI.
