# Media download skill

Use `yt-dlp` for supported public video URLs and `gallery-dl` for supported
social collections. Keep the runtime global under `Harness/extensions` and
pass only metadata, transcript, visual segments, and comment evidence to the
research subagent. BrowserOS Neo remains the authenticated page/session route.

The generic runner accepts a safe output stem and can omit adapter info JSON
when a platform skill already owns the metadata artifact. It never accepts a
cookie file and never stores raw session material.
