# Source discovery

Use the extension source catalog to diversify discovery before reading deeply.
Prefer canonical pages, official accounts, repositories, papers, and original
video posts. Record the query, adapter, canonical URL, access scope, and any
failure. Discovery does not make a source authoritative; score the retrieved
evidence separately.
