# Comments

Use the platform adapter that actually succeeded, preferably visible
BrowserOS/API evidence. Set item, scroll, time, and retry bounds before
reading. Preserve comment URL or parent post URL, author handle when visible,
retrieval time, and access scope. Summarize themes separately from verbatim
claims; never present a small sample as population sentiment.
