# YouTube

Use `media-download` with the globally installed yt-dlp runtime for public
media. Prefer official metadata and captions when available; download only
when transcript or visual evidence is needed. Keep the canonical URL and
timestamps, and pass compact artifacts to `video-asr` or `video-vlm`.
